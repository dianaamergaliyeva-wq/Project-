# Sites: вебинар для педагогов

Готовая презентация из восьми слайдов и итоговый опрос из существующего проекта work/webinar-poll.

Откройте index.html для презентации или poll.html для опроса. Параметр poll.html?results показывает общую сводку. Публикация: GitHub Pages, main, / (root).

Ответы сохраняются в Google Таблице организатора через опубликованный Google Apps Script. Имена и контакты не запрашиваются. Случайный идентификатор браузера позволяет обновить ответ без дублирования. Участникам доступна только общая сводка. Таблица остаётся доступна только владельцу.

Сообщение об успешном сохранении показывается только после ответа Google. При ошибке можно повторить отправку. Начать заново не удаляет ранее сохранённый ответ: он обновится после новой отправки.
